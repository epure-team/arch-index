# Integration notes — first product slice (read-only preparation)

No product implementation or native test has been changed yet. The comparison setup must pass first. These notes identify existing integration points, not permission to widen the validated scope.

- arch_index_cmt.ml: build_binding_names and build_local_fn_stamps already traverse named structures, recursive modules, literal includes and functor bodies, preserving stored #N names. Reuse those actual body records. Traversal alone does not establish ownership; an exported-member map rooted in the actual module binder is still needed.
- A Pdot member supplies a name selected inside an already-proven owner, not a global value Ident. Refuse any unknown intermediate owner. Source-order export replacement/masking is semantic shadowing, not global last-writer name guessing.
- Existing Head_enumerated can represent a bounded local body without a MUST promotion; its global resolver already checks dropped local definitions. This may avoid introducing a new head constructor requiring out-of-scope arch_index.ml changes. Point-free rows still use the ordinary-head/value_alias contract, not blanket Head_enumerated rewriting.
- At least add_arg_escapes, add_path_call and record_head need consistent new identity lookup. Texp_apply's head_arity also needs known-body syntactic arity; changing only record_head loses the overapplication return residual. Do not rewrite classify_head_path's user configuration matching merely to make it symmetric.
- call_graph_extractor.ml builds per-CMT tables and visits only top-level callers. Its current callee_file lookup is a global name_to_file map. Newly proven local bodies require same-file row existence, otherwise None; preserve caller naming and do not claim expanded nested coverage. The fallback helper itself is not exported by its mli. Existing point_free_aliases.ml uses the public flat index_project integration path. A private direct probe or inline test may be needed for deterministic same-name decoys without public interface expansion.
- Native fixture patterns: module_alias_heads.ml uses with_fixture + index_raw_into + exact SQL assertions. dropped_node_dependents.ml demonstrates a rejecting function-row trigger for dropped_node coverage. Read the relevant file completely before reusing its procedure. A failed process/import is not test RED.
- lib/arch_index/dune supports inline tests; arch_index_cmt is private. tezt tests link arch_index but it does not publicly re-export Call_graph_extractor. Do not assume a new native test can simply call that private collector API.

If existing API exposure or head representation proves insufficient, record a concrete blocker and amend the plan/intake scope before editing additional files. Prefer existing integration paths over a new public testing API.
