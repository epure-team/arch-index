# Independent plan voices

Sequential fresh contexts, intake only: Sol voice1, then Terra voice2. No source,
spec/research or other voice output was given to either. Unavailable Claude tier
mapped to user-approved Sol. Reports below are operator condensations, not verbatim
transcripts; full role responses remain in the tool conversation.

## Voice1 (Sol)

Proposed ten steps: freeze contract; minimal ordinary-application end-to-end slice;
rebuild safety; all immediate shapes; descriptors/locations; shadow-safe identity;
atomic input publication and completeness; query validation/exits; compatibility;
documentation/full gates. Main concerns: transaction/marker ordering, exact path
identity, vacuous counts, unsupported-versus-failed collection, no graph mutation,
full-validation cost, renderer/exit semantics, concurrency, stale artifacts and
schema-version consumers. Asked precise descriptor/output, order, selection,
provenance, count meaning, failed-input persistence, read snapshot and migration
questions. Did not recommend changing the bounded catalogue goal.

## Voice2 (Terra)

Proposed contract; persistence/lifecycle; minimal collector; all shapes; read-only
query; regression/documentation gates. Main concerns: generic walker omissions or
double count, immediate-node granularity, transaction scopes, stamp/location-based
identity, stale markers, validation after limits/output, graph refactor drift.
Asked exact fields/keys, valid-empty, unsupported/partial distinction, consistency
predicate and copied/symlink path serialization. Did not recommend a direction change.
