or review GO implied. All are resolved below from the intake, source or narrower
refusal; no user scope expansion or invented response.

## Edge cases

- EC-1 [US-1,C-2,C-3]: shadowed binder plus ghost/same-location nested literal ->
  exact admitted root body; reject ambiguous correspondence, never nested/homonym.
- EC-2 [US-1,C-5,C-6,C-15]: omitted labeled slot versus full overapplication ->
  actual supplied count, preserved partial flag and one residual only when overapplied.
- EC-3 [US-2,C-1,C-7,C-8]: parent rejected plus homonymous stored body -> dropped_node
  TOP on supported new invocation, no homonym fallback.
- EC-4 [US-2,C-9,C-13,C-14]: computed/effectful open -> original rows/effects/flat
  unchanged, new admission absent.
- EC-5 [US-2,C-11,C-12]: identical canonical rows with different native candidates ->
  refuse unless full native group agrees and exact multiplicity is discharged once.
